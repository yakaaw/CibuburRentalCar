
## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Kalender Sewa"

2. **Month Navigation**
   - Previous month button (<)
   - Current month and year display
   - Next month button (>)

3. **Calendar View**
   - Day headers (Min, Sen, Sel, Rab, Kam, Jum, Sab)
   - Calendar grid showing dates
   - Current date highlighted (■)
   - Available dates marked (█)
   - Unavailable dates marked (░)

4. **Legend**
   - Explanation of color coding
   - Current date indicator
   - Available date indicator
   - Unavailable date indicator

5. **Action Button**
   - "Pilih Tanggal" button

6. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
