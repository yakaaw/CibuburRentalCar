## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Profil"

2. **Profile Picture**
   - User profile image
   - Camera icon (📷) for changing profile picture

3. **Personal Information**
   - Full name
   - Email address
   - Phone number
   - Address
   - Date of birth
   - Gender

4. **Action Buttons**
   - "Edit Profil" button
   - "Riwayat Penyewaan" button (to view rental history)
   - "Pengaturan Akun" button (account settings)
   - "Keluar" button (logout)

5. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
