## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Pusat Bantuan"

2. **Search Bar**
   - Search icon (🔍)
   - Placeholder text "Cari bantuan..."

3. **Help Categories**
   - Grid layout showing help categories:
     - Cara Sewa (How to Rent)
     - Pembayaran (Payment)
     - Mobil (Cars)
     - Booking

4. **FAQ Section**
   - Common questions with expandable answers (▶)
   - Questions about booking process, requirements, payment, driver service, and damage handling

5. **Contact Information**
   - "Hubungi Kami" section
   - Phone number
   - Email address

6. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
