## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Detail Mobil"

2. **Image Carousel**
   - Multiple images of the car
   - Indicator dots for navigation

3. **Car Information**
   - Car name/model
   - Rating and review count
   - Daily rental price
   - Special pricing for longer rentals

4. **Specifications Section**
   - Car type
   - Transmission type
   - Fuel type
   - Passenger capacity
   - Year of manufacture

5. **Description Section**
   - Detailed description of the car
   - Key features and benefits

6. **Facilities Section**
   - List of included facilities/features

7. **Action Button**
   - "Sewa Sekarang" (Rent Now) button

8. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
