## UI Elements

1. **Header**
   - Page title "Dashboard Admin" with chart icon (📊)

2. **Daily Statistics**
   - Three cards showing key metrics:
     - Revenue (📈 Pendapatan)
     - Cars (🚗 Mobil)
     - Users (👤 Pengguna)

3. **Recent Bookings Section**
   - List of recent bookings with:
     - Booking ID
     - User name
     - Car model
     - Rental dates
     - Status

4. **Cars Needing Attention**
   - List of cars requiring maintenance/service:
     - Car model
     - Status
     - Service date

5. **Action Buttons**
   - "Lihat Semua Statistik" button
   - "Kelola Mobil" button

6. **Navigation Bar**
   - Dashboard (📊)
   - Cars (🚗)
   - Calendar (📅)
   - Settings (⚙️)
