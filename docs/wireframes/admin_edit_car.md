## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Edit Mobil / Tambah Mobil"

2. **Car Images**
   - Multiple image uploaders with camera icons (📷)
   - Add image button (➕)

3. **Car Information Fields**
   - Car name input field
   - Brand input field
   - Type input field
   - Transmission selection with radio buttons (Manual/Otomatis)
   - Fuel type input field
   - Passenger capacity input field
   - Year input field
   - Daily rental price input field

4. **Facilities**
   - Checkboxes for available facilities:
     - AC
     - Audio System
     - Airbag
     - Power Windows

5. **Description**
   - Text area for car description

6. **Status**
   - Radio buttons for car status:
     - Tersedia (Available)
     - Disewa (Rented)
     - Maintenance

7. **Action Buttons**
   - "Batal" button to cancel changes
   - "Simpan" button to save changes

8. **Navigation Bar**
   - Dashboard (📊)
   - Cars (🚗)
   - Calendar (📅)
   - Settings (⚙️)
