## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Booking Mobil"

2. **Car Information**
   - Car name/model
   - Daily rental price

3. **Rental Date Selection**
   - Start date picker (📅)
   - End date picker (📅)
   - Duration display (number of days)

4. **Pickup Time**
   - Time picker (⏰)
   - Default time (09:00)

5. **Pickup Location**
   - Location selector (📍)
   - Default location (Cibubur)

6. **Return Time**
   - Time picker (⏰)
   - Default time (17:00)

7. **Return Location**
   - Location selector (📍)
   - Default location (Cibubur)

8. **Driver Option**
   - Radio buttons for driver selection
   - With driver option (+ Rp 150.000/hari)
   - Without driver option (default selected)

9. **Additional Information**
   - Text input for additional notes

10. **Cost Summary**
    - Rental cost breakdown
    - Driver cost (if applicable)
    - Total cost

11. **Action Button**
    - "Konfirmasi Booking" button

12. **Navigation Bar**
    - Home (🏠)
    - Calendar (📅)
    - History (📋)
    - Profile (👤)
