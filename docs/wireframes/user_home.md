## UI Elements

1. **Header**
   - Logo on the left
   - App name
   - Menu button (≡) on the right

2. **Search Bar**
   - Search icon (🔍)
   - Placeholder text "Cari mobil..."

3. **Promotional Banner**
   - Special offer announcement
   - Discount information

4. **Car Categories**
   - Filter options: SUV, MPV, Sedan, Hatchback, All

5. **Popular Cars Section**
   - Grid layout showing car images
   - Car name
   - Daily rental price
   - Rating and review count

6. **View All Cars Button**
   - Call-to-action to see all available cars

7. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
