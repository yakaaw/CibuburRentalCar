## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Pengaturan Admin"

2. **Profile Picture**
   - Admin profile image
   - Camera icon (📷) for changing profile picture

3. **Admin Information**
   - Admin name input field
   - Email address input field
   - Phone number input field
   - Address input field

4. **Security Settings**
   - Current password input field
   - New password input field
   - Confirm new password input field

5. **Notification Settings**
   - Checkboxes for email notifications:
     - New booking notifications
     - Payment notifications
     - Maintenance notifications
   - Checkbox for SMS emergency notifications

6. **System Settings**
   - Checkbox for automatic booking confirmation
   - Checkbox for displaying price including driver
   - Checkbox for 24-hour return time limit

7. **Action Button**
   - "Simpan Perubahan" button to save settings

8. **Navigation Bar**
   - Dashboard (📊)
   - Cars (🚗)
   - Calendar (📅)
   - Settings (⚙️)
