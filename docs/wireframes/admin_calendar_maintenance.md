## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Kalender Maintenance"

2. **Month Navigation**
   - Previous month button (<)
   - Current month and year display
   - Next month button (>)

3. **Calendar View**
   - Day headers (Min, Sen, Sel, Rab, Kam, Jum, Sab)
   - Calendar grid showing dates
   - Current date highlighted (■)
   - Scheduled maintenance dates marked (█)
   - Available dates marked (░)

4. **Legend**
   - Explanation of color coding
   - Current date indicator
   - Scheduled maintenance indicator
   - Available date indicator

5. **Action Button**
   - "Pilih Tanggal untuk Maintenance" button

6. **Scheduled Maintenance List**
   - List of upcoming maintenance schedules with:
     - Car name/model
     - Maintenance date
     - Cancel button

7. **Navigation Bar**
   - Dashboard (📊)
   - Cars (🚗)
   - Calendar (📅)
   - Settings (⚙️)
