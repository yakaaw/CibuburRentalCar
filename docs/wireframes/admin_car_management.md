## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Manajemen Mobil"

2. **Search Bar**
   - Search icon (🔍)
   - Placeholder text "Cari mobil..."

3. **Filter Options**
   - Tabs to filter cars by status
   - Options: Semua (All), Tersedia (Available), Disewa (Rented), Maintenance

4. **Sort Options**
   - Dropdown or buttons to sort cars
   - Options: Terbaru (Newest), Harga Terendah (Lowest Price), Harga Tertinggi (Highest Price)

5. **Car List**
   - Grid layout showing car cards with:
     - Car image
     - Car name/model
     - Daily rental price
     - Status
     - Action buttons (Edit, Detail)

6. **Action Button**
   - "Tambah Mobil Baru" button to add a new car

7. **Navigation Bar**
   - Dashboard (📊)
   - Cars (🚗)
   - Calendar (📅)
   - Settings (⚙️)
