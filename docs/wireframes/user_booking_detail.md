## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Detail Booking"

2. **Booking Status**
   - Current status display (Aktif, Selesai, Dibatalkan)

3. **Booking ID**
   - Unique booking identifier

4. **Car Information**
   - Car name/model
   - Daily rental price

5. **Rental Date Information**
   - Start and end dates
   - Duration in days

6. **Pickup Information**
   - Pickup time
   - Pickup location

7. **Return Information**
   - Return time
   - Return location

8. **Driver Information**
   - Driver status (Dengan Driver / Tanpa Driver)

9. **Additional Information**
   - Any additional notes from the booking

10. **Cost Summary**
    - Rental cost breakdown
    - Driver cost (if applicable)
    - Total cost

11. **Action Buttons**
    - "Batalkan Booking" button
    - "Edit Booking" button

12. **Navigation Bar**
    - Home (🏠)
    - Calendar (📅)
    - History (📋)
    - Profile (👤)
