## UI Elements

1. **Header**
   - Back button (←)
   - Page title "Edit Profil"

2. **Profile Picture**
   - Current profile image
   - "Ganti Foto" button with camera icon (📷) for changing profile picture

3. **Editable Fields**
   - Full name input field
   - Email address input field
   - Phone number input field
   - Address input field
   - Date of birth input field with calendar picker (📅)
   - Gender selection with radio buttons (Laki-laki/Perempuan)

4. **Action Buttons**
   - "Batal" button to cancel changes
   - "Simpan" button to save changes

5. **Navigation Bar**
   - Home (🏠)
   - Calendar (📅)
   - History (📋)
   - Profile (👤)
